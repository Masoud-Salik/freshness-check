# FreshCheck AI 🔎

**Check whether the facts in an AI-generated answer are still up to date.**

AI answers can sound confident while relying on information that has changed: an old software version, an outdated price, a former company executive, or a statistic presented as current.

FreshCheck AI explores a focused question:

> **Can I still trust the factual information in this AI-generated answer today?**

Rather than acting as another general-purpose chatbot, FreshCheck is designed around claim-level freshness assessment and evidence-backed verification.

## The problem

An answer isn't necessarily reliable just because it was once correct. Some facts change quickly; others remain stable for decades. A useful checker must distinguish between those cases instead of treating every old statement as outdated.

## How it is designed to work

1. **Submit an answer** — paste text generated by an AI assistant.
2. **Extract claims** — identify individual factual statements that can be checked.
3. **Assess freshness risk** — determine which claims are likely to change over time.
4. **Find current evidence** — search for relevant sources, prioritizing authoritative material.
5. **Evaluate support** — compare the evidence with each claim.
6. **Review the report** — see claim-level findings, explanations, and source links.

## What makes freshness different from fact-checking?

Freshness and correctness are related, but they are not the same.

| Dimension | The question it answers |
|---|---|
| Freshness risk | Is this type of claim likely to change over time? |
| Evidence support | Does current evidence support or contradict the claim? |
| Verification confidence | How strong and sufficient is the available evidence? |

A claim should not be labelled outdated merely because it is old. The assessment should explain what the evidence shows—and what remains uncertain.

## Technical direction

The project brief identifies two key integrations:

- **[Tavily](https://tavily.com/)** — web search and retrieval of current evidence.
- **[Bifrost by Maxim AI](https://www.getbifrost.ai/)** — a model gateway for AI-powered analysis.

Proposed application technologies include:

- React, TypeScript, Vite, and Tailwind CSS for the frontend.
- Python and FastAPI for the backend.
- GitHub for version control.

These describe the project's technical direction, not a claim that every integration or component is already complete.

## Project context

FreshCheck AI was developed around the **Geek Room Global AI Hackathon 2026** challenge: building a stale-answer detector for AI applications.

The project is being explored by a team of three, with an emphasis on a practical MVP, transparent assessments, and honest handling of incomplete or conflicting evidence.

## Principles

- **Evidence over confidence** — show sources and explain the reasoning.
- **Transparency over false precision** — don't present uncalibrated model scores as probabilities.
- **Uncertainty is a valid result** — say when a claim cannot be verified.
- **Simplicity over unnecessary complexity** — prioritize a useful core workflow.
